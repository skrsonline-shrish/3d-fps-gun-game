# Arena Strike 3D

A fast, browser-based 3D arena shooter inspired by compact arcade battle games. This project is built with Three.js and Vite for quick local gameplay.

## Features
- 3D arena environment
- WASD movement
- Mouse-look camera
- Click-to-shoot combat
- Enemy bots with chase-and-attack AI
- Health, ammo, and score HUD
- Restartable match flow

## Run locally

```bash
npm install
npm run dev -- --host 0.0.0.0
```

Then open the local Vite URL in your browser.

## Build for production

```bash
npm run build
```

## Controls
- W / A / S / D: move
- Mouse: aim
- Left click: shoot
- Shift not required; pointer lock is used for aiming
